# Linda-Pro 2.0.3.3

## ru

• Вкладки: можно держать несколько текстов рядом (до 8, кнопка «+» или Ctrl+T). У каждой вкладки свой текст, файл и результат, переключение ничего не теряет.
• Проверка привязана к своей вкладке: пока она идёт, можно печатать в другой, а когда закончится, у вкладки загорится зелёная точка. Одновременно идёт одна проверка.
• Файл из проводника («Проверить в Linda-Pro») открывается в новой вкладке и не затирает текущий текст.
• Закрытие вкладки с идущей проверкой её отменяет.

## en

• Tabs: keep several texts side by side (up to 8, the + button or Ctrl+T). Each tab has its own text, file and result, and switching loses nothing.
• A check belongs to its own tab: while it runs you can type in another one, and when it finishes the tab shows a green dot. One check runs at a time.
• A file from Explorer (“Check in Linda-Pro”) opens in a new tab and does not overwrite the current text.
• Closing a tab whose check is running cancels that check.

## pl

• Karty: kilka tekstów obok siebie (do 8, przycisk + lub Ctrl+T). Każda karta ma własny tekst, plik i wynik, a przełączanie niczego nie gubi.
• Sprawdzanie należy do swojej karty: gdy trwa, można pisać w innej, a po zakończeniu karta pokazuje zieloną kropkę. Naraz trwa jedno sprawdzanie.
• Plik z Eksploratora („Sprawdź w Linda-Pro”) otwiera się w nowej karcie i nie nadpisuje bieżącego tekstu.
• Zamknięcie karty z trwającym sprawdzaniem anuluje je.
