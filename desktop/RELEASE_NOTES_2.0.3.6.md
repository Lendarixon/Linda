# Linda-Pro 2.0.3.6

## ru

• После загрузки новых моделей программа предлагает «Перезапустить» вместо повторной кнопки «Обновить модели».
• Старое сообщение о неудачной установке («Installer exit code 5») больше не показывается при каждом запуске, если эта версия уже установлена.
• При проверке нескольких файлов строки таблицы больше не мигают.
• Короткий текст (меньше 150 слов): над результатом заметное предупреждение, что оценка может быть неточной.
• Правую панель результатов можно растянуть или сузить за разделитель между текстом и результатом (двойной щелчок — вернуть).
• Окно загрузок встроенного браузера больше не закрывает кнопки сверху справа.

## en

• After new models are downloaded the app now offers “Restart” instead of showing the “Update models” button again.
• An old failed-install message (“Installer exit code 5”) is no longer shown at every start once that version is installed.
• Rows of the batch table no longer flicker while several files are being checked.
• Short text (under 150 words): a clear warning above the result that the estimate may be inaccurate.
• The results panel can be widened or narrowed by dragging the divider between the text and the results (double-click resets it).
• The built-in downloads flyout no longer covers the buttons at the top right.

## pl

• Po pobraniu nowych modeli program proponuje „Uruchom ponownie” zamiast ponownie pokazywać przycisk aktualizacji modeli.
• Stary komunikat o nieudanej instalacji („Installer exit code 5”) nie jest już pokazywany przy każdym uruchomieniu, gdy ta wersja jest już zainstalowana.
• Wiersze tabeli nie migają już podczas sprawdzania kilku plików.
• Krótki tekst (poniżej 150 słów): wyraźne ostrzeżenie nad wynikiem, że ocena może być niedokładna.
• Panel wyników można poszerzyć lub zwęzić przeciągając separator między tekstem a wynikami (podwójne kliknięcie przywraca).
• Okno pobierania wbudowanej przeglądarki nie zasłania już przycisków w prawym górnym rogu.
