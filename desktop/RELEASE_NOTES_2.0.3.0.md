# Linda-Pro 2.0.3.0

## ru

• Окно настроек больше не скрывается под верхней панелью.
• Видеокарта выбирается автоматически надёжнее: дискретная карта определяется по объёму видеопамяти, самая мощная идёт первой.
• Полосы прогресса при загрузке и чтении файла, анализе, пакетной проверке и сравнении документов.
• Язык интерфейса переключается кнопками RU / PL / EN в шапке; у настроек появилась иконка шестерёнки; тема, размер шрифта и выбор устройства вынесены в левую панель.
• Выбор режима и моделей убран в сворачиваемый блок «Для опытных»: по умолчанию экран проще.
• Список изменений в программе показывает только номера и названия обновлений со ссылкой на полный список.
• Кнопка «Проверить обновления» перенесена в раздел обновлений.

## en

• The settings window no longer hides under the top bar.
• Automatic graphics-card choice is more reliable: a discrete card is recognised by its video memory and the most powerful one comes first.
• Progress bars for file upload and reading, analysis, batch checks and document comparison.
• The interface language switches with RU / PL / EN buttons in the header; settings got a gear icon; theme, font size and device choice moved to the left panel.
• Analysis mode and model choice moved into a collapsible Advanced block, so the default screen is simpler.
• The in-app change list shows only version numbers and titles with a link to the full list.
• The Check for updates button moved to the updates section.

## pl

• Okno ustawień nie chowa się już pod górnym paskiem.
• Automatyczny wybór karty graficznej jest pewniejszy: karta dyskretna jest rozpoznawana po pamięci wideo, najmocniejsza jest pierwsza.
• Paski postępu przy wczytywaniu i odczycie pliku, analizie, sprawdzaniu wsadowym i porównywaniu dokumentów.
• Język interfejsu przełączają przyciski RU / PL / EN w nagłówku; ustawienia mają ikonę koła zębatego; motyw, rozmiar czcionki i wybór urządzenia przeniesiono do lewego panelu.
• Wybór trybu i modeli przeniesiono do zwijanego bloku „Zaawansowane”: domyślny ekran jest prostszy.
• Lista zmian w programie pokazuje tylko numery i tytuły aktualizacji z linkiem do pełnej listy.
• Przycisk „Sprawdź aktualizacje” przeniesiono do sekcji aktualizacji.
