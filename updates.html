Linda-Pro updates

Changes to the Windows app and release history.

Current Windows release

2.0.3.0

06.10.2026
Download 2.0.3.0

Simpler interface: progress bars, language switch and quick settings, more reliable automatic graphics-card choice.

Full changelog
  • The settings window no longer hides under the top bar.
  • Automatic graphics-card choice is more reliable: a discrete card is recognised by its video memory and the most powerful one comes first.
  • Progress bars for file upload and reading, analysis, batch checks and document comparison.
  • The interface language switches with RU / PL / EN buttons in the header; settings got a gear icon; theme, font size and device choice moved to the left panel.
  • Analysis mode and model choice moved into a collapsible Advanced block, so the default screen is simpler.
  • The in-app change list shows only version numbers and titles with a link to the full list.
  • The Check for updates button moved to the updates section.

Previous releases

New release notes are available in English, Russian and Polish; older entries remain in English.

2026-10-06Linda-Pro 2.0.2.21 — New model ensemble 1.3: Russian, Polish and English
  • New 1.3 models (Essay and Multi, each merged from three trained variants) for all three languages. English now uses the same routed path as Russian and Polish, on shared models: switching language no longer reloads them.
  • Polish: on the main test set detection of AI text rose from 39% to 80% at 0.9% false flags (was 0.3%); Russian: 57% to 78% at the same 0.6% false flags; English: recent-model and humanized texts are caught noticeably more often (HumanizerBench 70% to 81%).
  • Honest limits: in English, false flags rose slightly on non-native writing (TOEFL exam essays: 4.4% to 6.6% on 91 texts) and on lightly edited human text. In Precise mode the same TOEFL essays give 1.1% false flags (1 of 91), at the cost of catching fewer English AI texts (HumanizerBench 69%). Use it for schools and universities.
  • The model package is about 4 GB; peak GPU memory is about 1.6 GB. The update does not delete old model folders.

The verdict threshold was frozen on development data; the website test sets were not used for selection.

2026-10-04Linda-Pro 2.0.2.20 — Data protection, PDF reports and blank-window fix
  • PDF reports now use the bundled renderer without Edge, Chrome or Brave. One A4 layout includes vector charts, structure map, metrics, annotated text and Unicode for English, Russian and Polish. Silent switching to the old exporter has been removed.
  • PDF/DOCX parsing runs in a separate Windows LPAC process with restricted file and network access. Limits remain: 20 seconds, 512 MiB, 20 MB input, 4 MB output and 500 PDF pages; DOCX entry count and expansion are bounded.
  • Current-user Windows DPAPI encrypts history. Existing records migrate into protected storage; writes are atomic and deletion respects retention policy.
  • Restart and page-refresh drafts also use DPAPI. New text is no longer stored in plaintext sessionStorage; legacy drafts migrate while preserving text.
  • The audit ledger uses an HMAC chain, independent checkpoint and recovery of interrupted writes. Manual clearing is disabled; organization retention policy controls storage.
  • Fixed the blank WebView2 window after minimizing: the surface repaints without reloading the page or losing input. The dark window background is retained.
  • An explicit PerMonitorV2 DPI manifest is included, with Windows long-path support for the temporary document worker.
  • DirectML checks the actual execution provider. Switching CPU/GPU releases previous sessions and refreshes device status.
  • Fixed isolated document-worker preparation and error handling: damaged documents do not block subsequent work or expose internal paths to users.
  • Background update download, hidden installation, automatic relaunch and unsaved-text recovery remain supported. The stable channel serves the normal Windows installer separately from Dev.

Model weights, calibrations and commercial terms are unchanged.

2026-10-04Linda-Pro 2.0.2.17 — Updates, documents, single models and Metro UI
  • Background update download, hidden installation and automatic app relaunch; fixed the helper waiting indefinitely after a successful install.
  • Installer failure reopens the previous app, records the error and allows retry; failed packages are not automatically relaunched.
  • Unsaved text is restored after updating; temporary drafts are acknowledged and removed, respecting storage policies.
  • Duplicate update clicks are blocked, notes match the offered version, and restart is blocked during analysis, queued work or document parsing.
  • Package signature, size, version and checksum are verified. Failed model updates roll back changed, added and deleted files with the manifest; fixed open-file handling on Windows.
  • Cancellation belongs to a job and tab, covering early cancellation, page reload and disconnect. Cancelled results are not stored in history.
  • PDF/DOCX use a separate process: 20-second timeout, 512 MiB memory cap, 20 MB input, 4 MB output, PDF up to 500 pages; DOCX entry and expansion limits. Parsing keeps HTTP responsive.
  • Late uploads cannot overwrite newer input; damaged documents fail without blocking subsequent work.
  • Legacy single mode executes only the selected model. CPU voters load on demand, with optional preload.
  • Single verdict/probability agree with history and JSON/CSV/HTML exports, including model and analysis scope.
  • Stylo without sentence evidence no longer displays NaN, fabricated authorship shares or a human-authorship claim. Missing scores and text analytics without labels are handled correctly.
  • Uncertain sentences are not exported as explicit AI signals. Missing highlighting does not establish human authorship.
  • Precise mode requires the full ensemble; UI resets incompatible choices and API rejects them before model loading. Routed calibration supports the full ensemble.
  • Editing text, mode or model invalidates stale results. Fixed human-verdict confidence, zero scores, history percentages and opening history records.
  • Atomic settings; Origin/Host and iframe protections; CSV formula escaping; storage/export/folder/licence policies respected.
  • Metro UI: flat colours, square corners, keyboard focus and reduced motion. History / Batch / Compare centred on the window, using a separate row on narrow windows.
  • Status polling has a timeout; translations no longer redraw continually; update errors avoid blocking dialogs.
  • Website mobile menu closes on Escape, navigation and outside clicks; full release notes added.

Weights and calibrations are unchanged.

2026-10-03Windows app 2.0.2: one-click update and working report export (2.0.0 and 2.0.1 need a manual install)

2.0.1 fixed the export buttons (PDF, HTML, CSV, JSON, Markdown), which did nothing in the app window; 2.0.2 fixes the in-app update: after the download a Restart and update button appears and the app installs the new version by itself. If you have 2.0.0 or 2.0.1, the update button in those versions cannot install anything: please download Linda-Setup.exe from the latest GitHub release once and run it over your current copy (history, settings and models are kept). From 2.0.2 on, updates work from inside the app.

2026-10-03Windows app 2.0: PDF reports, updates without reinstalling, Russian and Polish interface

What is new: a PDF report with charts (probability along the text, authorship shares, where the text sits against human and AI samples, structure map), plus HTML, CSV and JSON exports; updates download in the background and apply after a restart, with rollback if something goes wrong; the interface in Russian, Polish and English; appearance settings (theme, accent, density, font size, corners); for organizations: batch check of a whole folder, an audit log and policies in enterprise.json. The word and character counter is fixed. The models are unchanged (version 1.1). Version 1.x updates itself from inside the app.

2026-10-03Windows app 1.2.1: the colour map now agrees with the verdict

Fix for version 1.2: on polished AI texts the verdict said AI while the sentences were all coloured as human, because one sentence is too short for the models on its own. Now every sentence is scored alone and in its context (about 120 words around it) and the higher score counts, so a whole AI text is shown as AI and a lone strongly-AI sentence still stands out. On our test texts 64-78% of the sentences of AI texts are marked AI and another 18-23% possibly AI, against 0% AI and 2% possibly-AI for human texts. The thresholds for AI and possibly-AI now come from the program itself, so the main window and the full reader always show the same colours. The models are unchanged. Versions 1.1.x and 1.2.0 update themselves from inside the app.

2026-10-02Windows app 1.2: history with folders, batch check, document comparison, text structure

What is new: (1) History kept only on your computer: every check is saved with its text and result; folders (drag a row onto a folder), search, sorting, bulk delete, automatic clean-up after 30, 90 or 365 days, switch it off any time. (2) Batch check: drop any number of PDF, DOCX, TXT or MD files and they are checked one after another, with CSV export. (3) Document comparison: two versions side by side with the passages they share (8+ identical words) and how the AI colouring changed; or an overlap matrix across many documents. (4) Full reader: open any saved check or compared document in the full analysis view and go back to the list. (5) Authorship verdict: human, mixed or AI, with shares of AI, possibly-AI and human text. (6) Text analytics and structure: sentence rhythm, lexical diversity, stock phrases, repeated phrases, an AI-probability strip along the text, a paragraph map and a violin plot of sentence scores against human and AI references. (7) Every sentence is scored on its own again (single AI sentences among human ones are visible), the possibly-AI band starts lower, and flat Metro animations. Everything still runs on your PC; nothing is uploaded. Limits: sentence-level detection is about 70-75% accurate, weaker than whole-text detection, and the structure view describes a text but is not part of the verdict. Version 1.1.x installs update themselves from inside the app.

2026-10-01Windows app 1.1.2: GPU acceleration for AMD, NVIDIA and Intel graphics cards

The app now runs the models on any DirectX 12 graphics card through DirectML, with no CUDA or ROCm installation: 8-12 times faster than the CPU on our test PC (AMD Radeon RX 9070 XT: 0.3 s for 1,000 words instead of 3.5 s), identical verdicts. Automatic mode uses a discrete card; the first start prepares the GPU models once (about a minute). Choosing GPU on a PC without a usable card no longer breaks the app: it falls back to the CPU.

2026-10-01Windows app 1.1.1: sharper colour map, faster start, licence keys

The colour map now follows sliding windows of about 300 words, so the boundary between human and AI-written passages is accurate to roughly 100 words, and the Multi view no longer stays green. The models can load right at start-up (Settings; turn it off and you get a warning that the first analysis will be slower). New Metro-style look for the app and the online demo. Licence keys are tied to the computer they are activated on and can be moved with Remove key; complimentary keys work offline. Version 1.1.0 installs update themselves from inside the app.

2026-10-01Linda-Pro 1.1: retrained against AI humanizers

The three detectors were retrained on real outputs of AI humanizer tools. On the public HumanizerBench set (not used for training) the share of humanized texts flagged as AI rose from 31% to 70%; false flags on TOEFL exam essays fell from 8.8% to 4.4%. The technical report (DOI 10.5281/zenodo.23080472) lists the data, tests and caveats.
