## Воспроизведение

Из `C:\Users\ninja\Desktop\Linda_2100_Dev`:

```powershell
$env:PYTHONIOENCODING='utf-8'
$env:LINDA_HOME='C:\Users\ninja\Desktop\Linda_2100_Dev\test_profile'
& C:\Users\ninja\Desktop\Linda_desktop\.venv\Scripts\python.exe -m pytest tests -q
& C:\Users\ninja\Desktop\Linda_desktop\.venv\Scripts\python.exe tools\verify_release_2100.py
```

Сборка: `tools\release_2100.py` (Python 3.12, готовый замороженный runtime рабочей установки). Намеренно отказывается перезаписывать существующую итоговую папку. Исходники/артефакты не удалять для повторной сборки: используйте другое имя BUILD в новой копии скрипта.

Реальные модели: `tools\qa_release_smoke.py`, лог `qa_real_exe_3.log`. Повторять только после проверки живых владельцев GPU и в новом разрешённом временном окне. Скрипт создаёт новый профиль при повторе, запускает модели строго последовательно и завершает свои EXE.

UI: `tools\qa_ui_server.py` (локальный сервер без моделей/обновлений), затем `node tools\qa_startup_ui.cjs`. Сервер после работы остановить по его PID. Источники состояния в UI-тесте подменяются, это не модельный benchmark.

Не запускать `publish_*.py` и старые release-скрипты автоматически: общий update feed не обновлялся, старые пути ведут к архивам. Исторический PENDING_NEXT_RELEASE.md отмечен как вошедший в эту локальную сборку.
