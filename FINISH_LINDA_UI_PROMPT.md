## Что изменено

### Общий интерфейс

`web/desktop-shell.js`, `web/desktop-shell.css`, `web/index.html`, `web/cabinet.html`, подключение оболочки в `linda_desktop/app.py`.
Постоянное меню, отдельные страницы, настройки по категориям, плоские Windows-подобные элементы, светлая/тёмная/контрастная темы, понятные подписи. Вставка не запускает проверку. История, пакетная проверка и старые функции сохранены. LocalDocs не редактировался.

### Исправление недоступного ввода

`web/startup.html`: сплэш ставил `inert` на детей body, затем новая оболочка переносила редакторы внутрь других элементов. При закрытии сплэша снимался inert только с текущих детей body; вложенные редакторы оставались заблокированы.
Добавлен `window.LINDA_modalLock(owner,nodes,on)`: хранит реальные заблокированные узлы и владельцев, снимает блокировку даже после переноса. Диалог установки моделей использует тот же механизм. Не заменять это безусловным снятием inert со всего документа: сломается настоящая модальность.

### Импорт документов

`linda_desktop/document_formats.py`, `documents.py`, `document_worker.py`, `document_sandbox.py`, `inbox.py`, `__main__.py`, разрешения папочной проверки в `app.py`.

Поддерживаемые расширения в `document_formats.SUPPORTED_EXTS`:
`.csv,.doc,.docx,.epub,.fb2,.htm,.html,.json,.log,.markdown,.md,.odt,.pdf,.rst,.rtf,.tex,.text,.tsv,.txt,.xhtml,.yaml,.yml`.

- DOC: OLE/Word 97–2003, разбор piece table основного текста; шифрованные и более старые варианты отклоняются явно. Есть настоящий тестовый DOC, созданный Word, с RU/PL Unicode.
- ODT: content.xml, абзацы/пробелы/таблицы.
- EPUB: OPF spine, порядок чтения; внешние/выходящие пути отклоняются; зашифрованные EPUB отклоняются.
- HTML: извлекается текст без выполнения JavaScript и загрузки внешних ресурсов; script/style/head исключаются.
- RTF: управляющие группы, Unicode, кодировки, игнорируемые назначения.
- FB2: текст body. Текстовые форматы читаются как текст; это не обещание надёжной оценки таблиц/списков.
- PDF без текстового слоя и защищённые документы могут не дать текста. OCR не добавлен. PPT/PPTX не добавлены.

Сохранена изоляция структурированных парсеров Windows AppContainer, лимиты времени/памяти/размера, отказ при невозможности изоляции. Не заменять запуском Word/LibreOffice над пользовательскими файлами.

`linda_desktop/linda_olefile.py` — копия уже имевшегося в LocalDocs vendored olefile; лицензия сохранена в `assets/olefile-LICENSE.txt` и заголовке исходника.

Frozen parser — отдельный `assets/document-parser/Linda-Document-Worker.exe`, уже пересобран через `tools/build_document_parser.py`. Его нельзя забывать при изменении worker. Dev sandbox копирует также document_formats.py и linda_olefile.py.

`tools/repack_exe.py`: новые модули document_formats/linda_olefile/task_cancel включены в EXTRA_MODULES. Обычный repack обновляет и web/assets.

В Humanize добавлены `huFileBtn`, скрытый `huFile`, загрузка через `/api/upload`, подписи входа/выхода. Ошибка сохраняет исходный текст. Если пользователь редактировал поле во время импорта, его изменения не перезаписываются. Trace также использует общий серверный парсер вместо отдельного FileReader.

### Остановка и положение гуманайзера

- Постоянная нижняя панель: `desktopGlobalStop`, виден при проверке, задачах инструментов и пакетной проверке, работает после смены страницы. Локальная кнопка `desktopStop` в проверке сохранена.
- Humanize `huStop`, встроенный гуманайзер `styleStop`, Trace `trStop`.
- `window.LINDA_tools` в desktop-shell.js выдаёт job_id/client_id, отслеживает операции, отправляет `/api/detect/cancel`, ждёт завершения серверного запроса. Статус «Останавливаем…» не должен выдавать незавершённую работу за остановленную.
- `linda_desktop/task_cancel.py`: cancellation event привязан к потоку запроса.
- `app.py`: async tool_work оборачивает humanize, humanize/loop и trace/corpus, регистрирует отмену в core.active_checks, учитывает disconnect и active_requests; переписывания сериализует tool_lock.
- `humanize_pack.py`: checks между стадиями/фрагментами/итерациями; Transformers StoppingCriteria проверяет event во время генерации. Перепроверка детектором получает тот же cancel event.
- `trace_pack.py`: progress callback проверяет отмену; `trace/outlier_engine.py` добавляет checkpoint перед обработкой символьных признаков каждого документа. Текущий нативный вычислительный вызов может завершиться до ближайшей точки отмены.
- API humanize/batch не переведён на новый tool_work. В текущем UI обращений к нему не найдено; проверь необходимость, не обещай охват всех внутренних API.
- Кнопка `desktopRewrite` сверху основного экрана переносит текущий текст на отдельную страницу. `stylePanel` перенесён к результату справа; подробные действия в details. Исправлено скрытие этого блока старым CSS простого режима. Кнопка `desktopRewriteResult` должна быть видна рядом с результатом и в простом режиме.
