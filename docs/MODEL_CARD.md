# Model card — Linda Assay and Linda Loupe

Current distribution: model package 1.5.0 (21 November 2026); Windows app 2.5.0.5 (24 November 2026). Old names: Linda-Pro and Linda-Pro Lite. Repository identifiers remain unchanged.

Assay, English: merged Essay-M (DeBERTa-v3-large), Multi-M (mDeBERTa-v3-base) and Stylo-D (LightGBM/ngrams); weights 0.8 Essay / 0 Multi / 0.2 style. Assay, Polish and Russian (since 1.4.1): a separate pair of the same architectures, `essay_l14m50` and `multi_l14m50`, weights 0.5 / 0.5, no stylometry voter. Document windows about 300 words, top25 aggregation. Multi can still provide independent local evidence for EN. Loupe: distilled ONNX student plus stylometry; EN 0.8 student / 0.2 style, RU/PL 0.8 student / 0.1 Stylo-D / 0.1 language-specific style. Decision rules are frozen in routing.json.

The current Loupe encoder config has 12 layers, hidden size 768 and 12 heads, consistent with multilingual-e5-base. The packaged speed_args.json still says e5-small; that provenance metadata inconsistency is disclosed and is not silently rewritten in a signed model release.

The Windows app uses Assay FP32 stable DirectML or CPU; Loupe CPU. Languages EN/PL/RU. Use for screening with human review, never as sole evidence of authorship or misconduct. Global confidence and local coverage are distinct. Short inserts and human-edited AI can be missed. Assay downloads about 5.8 GB (English 2.9 GB + Polish/Russian 2.9 GB); only one language's networks are held in memory at a time. Recommended Assay GPU memory is 8 GB; 4 GB cards get a smaller model budget since app 2.5.0.4 but are not measured by us. Loupe downloads about 0.3 GB.

Historical full-tier weights were introduced as 1.3.1; Loupe historical document metrics were measured for the packaged 1.3.3 pipeline. Package 1.3.4 added token outputs/heads; 1.5.0 replaces them with second-generation, Platt-calibrated heads for all six network/language pairs (new Russian heads; Russian heads are experimental, read their AUC rather than F1 at the fixed 0.20 threshold). Document verdicts are unchanged from 1.4.1. Small token heads are not independently validated for span accuracy; automatic Assay markup uses sentence/context evidence. [Benchmark brief](BENCHMARK_BRIEF.md) distinguishes historical accuracy and current engineering verification. No independent accuracy certification is claimed.

Training lineage, non-Llama filtering claims and limitations: DATA_BOM.md. The maintainer completed the source-rights review and confirmed rights for this distribution on 26 October 2026. The separate Stylo-Clean model is not the same lineage as Assay's Stylo-D.
